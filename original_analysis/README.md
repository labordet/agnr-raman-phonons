# Original research programs

These programs preserve scientifically useful source developed during the project. They include the global Lorentzian fits, the interactive configuration-III RBLM refinement and curation application, bounds and spectrum viewers, preprocessing applications, and figure/model scripts. The public paper command uses the portable programs in `paper_reproduction/`.

The `.py` programs copied from the Zenodo source collection and additional distinct project utilities preserve their original numerical methods. Historical default paths and graphical interfaces reflect their research use; they are not the recommended paper entry point. The reference-spectrum scripts describe an earlier Figure 1c treatment. The final paper panel uses the actual fitting means through `paper_reproduction/plot_fig1c_fitting_means.py`.

Optional graphical applications may need Tkinter, ttkbootstrap or seaborn. Install those only when using the relevant application. The full paper command does not require them.
