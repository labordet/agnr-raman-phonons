# Main-figure source programs

`Figure_2_cleaned_spectra_waterfall.py` is the original selected-spectrum waterfall generator. `Figure_3_temperature_shift_from_after.py` contains the zero-temperature-referenced frequency model, figure calculations and related table functions used for the final analysis. Their historical directory defaults remain in the source.

For a portable run against the Zenodo data archive, use `paper_reproduction/reproduce_all.py`. The archive includes the final artwork and editable assemblies for Figures 1–3; these scripts generate numerical components rather than the entire slide layouts.
